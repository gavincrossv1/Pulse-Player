# Pulse Player

Pulse Player（脉冲播放器）是一款专为 Windows 平台打造的现代本地离线媒体播放器。高度还原流媒体播放器的视觉质感与跟手操作手感，专注纯粹离线视听体验。

## 特性亮点
* **双态架构**：无参启动进入主页态（文件选择、全局拖拽起播、断点记忆续播）；关联双击视频直达播放态。
* **高质感跟手交互**：仿 B 站粉色悬浮展开进度条、跟随时间预览气泡、顶部紧凑穿透式胶囊 OSD。
* **长按状态机**：右键点按快进、长按提速至极速倍率（松开瞬间恢复）；左键点按快退、长按以 150ms 脉冲步退。
* **25+ 类格式原生硬解与高保真音频**：基于 libmpv 原生解码引擎，硬件直解低功耗，支持 0.1x~10.0x 无级微调倍速。
* **同目录选集抽屉**：智能扫描同目录音视频媒体文件并执行人类自然排序（Natural Sort），支持临时调序与逆序洗牌。
* **全局持久偏好与单片微调**：支持偏好设置持久化记忆，起播单片支持内存级微调，切集自动恢复。
* **独立软件音量体系**：应用内独立增益（0%~100%），绝不污染操作系统主音量。
