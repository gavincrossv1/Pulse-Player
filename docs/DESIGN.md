# Pulse Player 产品与交互设计规范文档 (DESIGN.md)

## 一、 设计哲学与核心原则

Pulse Player 旨在打造一款**高度还原现代流媒体播放器手感与视觉质感**的 Windows 本地离线播放器。
立足于**第一性原理**与 **KISS 原则**，杜绝传统播放器（如 PotPlayer、VLC）臃肿繁琐的配置包袱，彻底摒弃弹幕、在线登录与云端拉流，将所有体验细节聚焦于**本地视频播放的丝滑交互与纯粹观影体验**。

---

## 二、 双态架构与启动分流（Two-State UI）

软件界面分为两种明确的运行状态，根据启动入口精准分流：

```
       [直接打开软件本身 / 无参启动]   [选择视频 / 拖入文件]
应用启动 --------------------> 【主页态 (Home View)】 -------------> 【播放态 (Player View)】
   |                                 ^                                      |
   |                                 |----------- 点击 [回到主界面] ---------|
   |
   | [双击视频关联打开 / 命令行带路径]
   +------------------------------------------------------------------------> 直接开始播放 (直达播放态)
```

### 1. 启动分流生命周期规则
* **直接点击视频打开（直达播放态）**：
  - 用户在操作系统中**双击视频文件**、通过“打开方式”关联启动、或在命令行中携带视频文件路径启动时，播放器**必须直接进入【播放态】立即播放**，绝对不得多余弹出主页，确保“即点即播”的极速体验。
* **展示主页态的唯二场景**：
  1. **启动软件本身**：用户直接点击播放器图标、桌面快捷方式或无参启动时，进入【主页态】展示文件选择与拖拽引导；
  2. **主动返回**：在播放过程中，用户点击左上角【⌂ 回到主界面】按钮时，暂停播放并平滑切换回【主页态】。

### 2. 主页态（Home View - 软件主页）
* **定位**：未载入视频时的优雅引导界面，改变传统播放器空白黑框的冷冰体验。
* **视觉布局**：
  - 深黑背景（`#18191C`）与居中垂直排布；
  - 软件 Logo 与 “Pulse Player” 现代标题；
  - **核心操作区**：
    - 大号粉色主题按钮：`【选择本地视频】`（点击唤起系统原生文件选择器）；
    - 虚线拖拽区域：`【将视频文件拖拽至此处立即播放】`（支持全局拖入文件立即起播）；
  - **历史记录区与断点续播**：
    - 下方轻量列出最近打开的 5 个视频名称与路径；
    - **断点记忆**：记录最近视频退出时的播放进度时间戳；点击任意历史项即刻进入播放态，自动恢复至上次退出的进度点继续播放，同时触发 OSD 提示。

### 3. 播放态（Player View - 视频播放）
* 载入视频后平滑进入播放态，视口铺满画面，顶部标题栏与底部控制栏悬浮覆盖在视频上方。

## 三、 顶部导航与窗口交互规范

```
+-----------------------------------------------------------------------------------------+
| [⌂ 回到主界面]        [本地] 03讲 深度学习基础.mp4                     [📌] [-] [□] [✕] |
+-----------------------------------------------------------------------------------------+
```

### 1. 左侧功能区
* **`【⌂ 回到主界面】` 按钮**：
  - 点击后暂停当前视频，并由播放态无缝切回【主页态】。

### 2. 居中标题区
* 格式化展示：`[本地] 视频完整文件名.后缀`。
* 文本居中对齐，超出宽度时采用中间或末尾省略号（`...`）截断。

### 3. 右侧窗口控制组
* **置顶图钉按钮（Pin）**：
  - **未置顶**：图标为 45° 倾斜图钉（白色线条）；
  - **置顶后**：图标变为 90° 垂直挺立图钉，并高亮 B 站标志粉（`#FB7299`）；
  - 窗口始终保持在其他应用程序上方。
* **剔除画中画/小窗模式**：遵循用户极简诉求，不增加冗余按键。
* **最小化（`-`）、最大化/还原（`□` / `❐`）、关闭（`✕`）**。
* **窗口系统级动画与手势规范**：
  - 必须保留 Windows 原生非客户区动画特性：
    - 点击最小化：具备平滑缩进任务栏的系统回弹动画；
    - 点击最大化：具备平滑铺满屏幕的展开动画；
    - 窗口拖拽与吸附：支持 Win+左右方向键及拖至屏幕顶部的 Aero Snap 分屏吸附。

## 四、 视口与 OSD 提示层规范

### 1. 视频视口（Video Viewport）
* 纯黑底色，支持高性能硬件加速解码输出。
* 默认保持视频原始物理宽高比居中显示。

### 2. 穿透式居中 OSD 提示层
* **属性**：鼠标完全穿透，点击与滚动不被 OSD 拦截，所有鼠标交互直达视口。
* **位置黄金律**：
  - **垂直定位在画面中上方（上 1/3 黄金分割处）**；
  - **设计初衷**：彻底避开画面正中央的关键人物面部/主体视觉，并完全避免遮挡底部字幕区域。
* **胶囊视觉样式**：
  - 半透明深黑背景（`rgba(0, 0, 0, 0.78)`），圆角 18px，白色加粗字；
* **提示场景**：
  - 键盘右方向键长按加速：常驻提示 `3.0x 快进中 >>`（松开瞬时消失）；
  - 点按快进/快退：临时展示 `+5秒` / `-5秒`（显示 800ms）；
  - 断点续播：展示 `已为您恢复上次播放进度`（显示 800ms）；
  - 音量调节：展示 `音量: 80%`（显示 800ms）；
  - 镜像/旋转/比例：展示 `水平镜像: 开启` / `画面旋转: 90°` / `视频比例: 铺满`（显示 1000ms）。

## 五、 底部悬浮控制台交互规范

```
+-----------------------------------------------------------------------------------------+
| [------------------ 仿 B 站粉色悬浮展开进度条  ------------------------] |
|                                                                                         |
| [▶] [⏮] [⏭]  00:27 / 05:57                    [选集] [倍速] [⚙] [🔊====] [⛶]            |
+-----------------------------------------------------------------------------------------+
```

### 1. 悬浮展开粉色进度条
* **常态**：3px 极细条，底槽浅白半透明，已播放部分为 B 站粉（`#FB7299`）；
* **悬浮/拖拽态**：膨胀为 6px，出现白底粉环圆点滑块；
* **时间预览气泡**：鼠标在进度条上移动时，光标正上方悬浮跟随显示时间气泡（如 `02:45`）；
* **跳转手感**：点击进度条任意位置立即瞬移 Seek；拖拽滑块持续 Seek。

### 2. 左侧控制项
* **播放 / 暂停切换（三通道触发）**：
  1. 点击底栏播放/暂停按钮；
  2. 单击画面任意区域（内置 250ms 防抖消除与双击冲突）；
  3. 键盘空格键。
* **上一集（⏮）与 下一集（⏭）**：
  - **下一集**：直接加载同目录下按自然排序的下一个视频；
  - **上一集（人性化判定）**：
    - 若当前播放时间 **$> 3.0$ 秒**：点击上一集先回滚重播当前集开头（防误触）；
    - 若当前播放时间 **$\le 3.0$ 秒**：点击上一集切换至真正的前一个视频。
* **时间标签**：`当前时间 / 总时长`（如 `00:27 / 05:57`）。

### 3. 右侧控制项与浮层卡片

#### (1) 【选集】抽屉卡片（目录播放列表）
* 鼠标悬浮或点击【选集】图标时向上滑出；
* **支持格式**：智能扫描当前视频所在文件夹中的主流视频格式，包含以下 16 类扩展名：
  `.mp4`, `.mkv`, `.avi`, `.flv`, `.mov`, `.wmv`, `.webm`, `.ts`, `.m4v`, `.rmvb`, `.rm`, `.m2ts`, `.vob`, `.mpg`, `.mpeg`, `.3gp`；
* 按文件名进行自然排序（Natural Sort，如 1, 2, 10 而非 1, 10, 2）；
* 标注序号、文件名与视频时长，**当前播放项高亮粉色**；点击任意项秒切播放。

#### (2) 【倍速】悬浮卡片
* 预设快捷按钮：`[0.5x]` `[0.75x]` `[1.0x]` `[1.25x]` `[1.5x]` `[2.0x]` `[3.0x]`；
* **0.1x ~ 10.0x 无级微调滑块**与微调增减按钮；
* 高亮当前激活倍速。

#### (3) 【设置】悬浮卡片（1:1 还原 B 站设置面板）
* **播放方式**：
  - `[自动切集]`：当前视频播放完毕后，自动连续播放同目录下自然排序的下一个视频；若已是列表最后一个视频则停止播放；
  - `[播完暂停]`：当前视频播放完毕后，自动暂停在最后一帧画面，不自动切集；
  - `[单集循环]`：当前视频播放完毕后，立即重回开头（00:00）重新循环播放当前视频；
  - `[列表循环]`：同目录下的全部视频按自然顺序依次连播，最后一个视频播放完毕后，自动循环回到第一个视频从头播放。
* **视频比例**：
  - `[自动]`：按视频物理原始宽高比等比居中渲染（画面两侧或上下保留黑边）；
  - `[4:3]`：强制按 4:3 比例缩放渲染；
  - `[16:9]`：强制按 16:9 比例缩放渲染；
  - `[铺满]`：无视原始宽高比，强制拉伸画面使其完全填满整个视口（无任何黑边）。
* **画面变换**：
  - `[水平镜像]`：水平镜像翻转画面（开 / 关）；
  - `[顺时针90°]`：每点击一次顺时针旋转 90°，在 0° $\to$ 90° $\to$ 180° $\to$ 270° $\to$ 0° 之间循环旋转。
* **播放策略 (解码模式)**：
  - `[推荐硬解]`：优先调用显卡硬件加速解码，实现低功耗、高帧率与极低 CPU 占用；
  - `[兼容硬解]`：备用硬件加速渲染通道，防止特殊显卡驱动或老旧环境下的渲染异常；
  - `[兼容软解]`：纯 CPU 软件解码模式，兜底兼容所有非标损坏或极度特殊的冷门编码视频。

#### (4) 浮层交互原则：鼠标移出即逝
* 用户鼠标移入按钮或点击唤起卡片；
* **关键设计**：当用户鼠标移出卡片区域后，触发 **300ms 离开缓冲防抖**，卡片自然平滑淡出隐藏；
* **绝不需要**用户再次回到按钮上去二次点击关闭。

#### (5) 独立软件音量体系
* **原则**：播放器调整的是**应用内音视频流的独立增益（0% ~ 100%）**，**绝不侵入修改 Windows 操作系统全局主音量**；
* **响度计算公式**：
  $$\text{实际输出听觉响度} = \text{系统主音量} \times \text{播放器内音量}$$
  *只要其中任意一项为 0，物理输出即为静音；彼此完全隔离*；
* **交互方式**：
  - 点击喇叭图标：静音 / 恢复原音量；
  - 鼠标悬浮/拖拽水平音量滑块；
  - 键盘方向键 $\uparrow$/$\downarrow$：步进调节 $\pm 5\%$；
  - 鼠标滚轮在视频画面任意区域滚动：无级增减音量。

#### (6) 全屏切换（三通道触发）
1. 点击底栏最右侧全屏按钮；
2. 鼠标双击画面任意区域；
3. 全屏状态下按键盘 `Esc` 键直接退出全屏。

## 六、 键盘按键与长按状态机规范

> [!IMPORTANT]
> **交互范围与按键定义说明**：
> 本文中所涉及的“左键”、“右键”等方向操作，**严格仅指键盘上的左右方向键（$\leftarrow$ / $\rightarrow$）**，绝不指代鼠标操作。
> 播放器接受的鼠标操作仅为通用的单击（防抖播放/暂停）、双击（全屏切换）、滚轮（音量调节）、拖拽进度条与窗口边缘拉伸缩放等通用操作，不设鼠标长按加速或其他冗余鼠标手势。

| 按键动作 | 触发判定 | 执行动作 | 视觉反馈 |
| :--- | :--- | :--- | :--- |
| **右方向键（$\rightarrow$）点按** | 按下并于 250ms 内释放 | 快进 5 秒（配置可调） | 上 1/3 处弹出 `+5秒` 胶囊 (800ms) |
| **右方向键（$\rightarrow$）长按** | 按下并持续按住 $>250$ms | 提速至 3.0x（配置可调）；松开瞬间瞬时恢复原倍速 | 上 1/3 处常驻 `3.0x 快进中 >>`，松开即刻隐藏 |
| **左方向键（$\leftarrow$）点按** | 按下并于 250ms 内释放 | 快退 5 秒（配置可调） | 上 1/3 处弹出 `-5秒` 胶囊 (800ms) |
| **左方向键（$\leftarrow$）长按** | 按下并持续按住 $>250$ms | 以高频脉冲（每 150ms 快退 5 秒）连续步退 | 上 1/3 处连续提示快退进度 |
| **空格键（Space）** | 点按 | 切换 播放 / 暂停 | 底栏播放按钮图标即时同步 |
| **上/下键（$\uparrow$ / $\downarrow$）** | 点按或长按 | 调节软件音量（步长 $\pm 5\%$） | 上 1/3 处弹出当前音量百分比胶囊 |
| **Esc 键** | 点按 | 若处于全屏则退出全屏；常规窗口不响应 | 窗口还原，恢复鼠标光标 |

## 七、 自动隐藏与全屏交互规范 (Auto-Hide & Fullscreen)

1. **全屏状态顶部栏隐藏**：
   - 全屏状态下，播放器顶部标题栏（包含窗口控制、置顶与回到主界面）严格隐藏，释放完整画面空间；
   - 退出全屏后恢复常规窗口悬浮标题栏。
2. **静止自动淡出**：
   - 鼠标在播放器视口内静止停滞超过 **2.5 秒**，下方的控制栏（及窗口态下的标题栏）平滑渐变消失；
   - 鼠标在画面中移动时立即唤醒显现并重置 2.5 秒倒计时；
   - 视频处于暂停状态下，静止超过 2.5 秒同样平滑渐变淡出，以便用户沉浸观察暂停画面细节与字幕。
3. **移出窗口立刻淡出**：
   - 光标从画面中移开到播放器之外（或失去焦点），控制栏与标题栏**立刻平滑渐变消失**，无任何延迟。
4. **防误隐保护机制**：
   - 进度条处于用户按压持续拖拽中时保持可见；
   - 【倍速】、【设置】或【选集】抽屉卡片处于展开交互时保持可见。

## 八、 约束与边界原则

本文档中没有提到的功能坚决不要实现（例如：弹幕系统、在线登录、字幕在线抓取、滤镜调色盘、云端拉流等），对本项目而言完全属于冗余过度设计。除非确认某功能对播放体验具有不可替代的基础性意义，否则必须严格遵守本文档设定的产品边界；若确需增补，须提前与用户沟通确认后再行纳入。
